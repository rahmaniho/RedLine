# استودیو کارن (RedLine — Karen Studio)

وب‌سایت تعاملی و گالری عکاسی **استودیو کارن**؛ ساخته‌شده با **React 19**، **TypeScript**، **Tailwind CSS v4**، **GSAP (Flip & Observer)** و **Vite**.

## ویژگی‌های پروژه

- **گالری افقی بی‌نهایت (Infinite Kinetic Rail):** حرکت پیوسته و نرم با پشتیبانی از اسکرول ماوس، درگ و لمس موبایل به کمک GSAP Ticker و Observer.
- **انیمیشن گذار یکپارچه (GSAP Flip Morph):** بزرگ‌نمایی نرم کارت‌های کپسولی هنگام هاور و تبدیل روان تصویر به نمای جزئیات کامل اثر و بازگشت دقیق به ریل گالری.
- **فیلتر دسته‌بندی آثار:** فیلتر آنی بین دسته‌های «همه»، «پرتره»، «عروسی» و «سفر» شامل ۲۴ اثر با متادیتا، برچسب‌ها و توضیحات فارسی.
- **۴ پوستهٔ رنگی زنده:** تغییر در لحظهٔ تم بصری بین «رز گِلی»، «آبی کانی»، «بنفشه» و «مشکی».
- **کشوی محتوای استودیو (Content Drawer):** شامل بخش‌های معرفی استودیو و اسلایدر اعضای تیم، بسته‌ها و تعرفه‌های خدمات، فرایند کار و فرم ثبت سفارش و تماس.
- **پشتیبانی کامل فارسی و راست‌به‌چپ (RTL):** تایپوگرافی فارسی با فونت‌های `Vazirmatn` و `Noto Naskh Arabic`، اعداد فارسی، آیکون‌های برداری (SVG) توکار و طراحی واکنش‌گرا برای موبایل و دسکتاپ.
- **بارگذاری هوشمند تصاویر (`SmartImage`):** دارای زنجیرهٔ جایگزین خودکار (تصویر اصلی ← تصویر جایگزین باکیفیت ← گرافیک برداری ادیتوریال در حالت آفلاین).

## ساختار پوشه‌ها

```text
RedLine/
├── public/
│   └── favicon.svg          # آیکون اختصاصی استودیو کارن
├── src/
│   ├── components/
│   │   ├── ContentPage.tsx  # کشوی معرفی استودیو، خدمات، تعرفه‌ها و فرم تماس
│   │   ├── Detail.tsx       # نمای جزئیات هر اثر عکاسی
│   │   ├── Gallery.tsx      # ریل گالری تعاملی و مدیریت انیمیشن‌های GSAP Flip
│   │   ├── Icon.tsx         # مجموعه آیکون‌های برداری بدون وابستگی خارجی
│   │   ├── SmartImage.tsx   # کامپوننت بارگذاری مقاوم تصاویر با Fallback
│   │   └── TopNav.tsx       # نوار ناوبری بالا، فیلتر دسته‌بندی، انتخاب تم و منوی موبایل
│   ├── data/
│   │   ├── photos.ts        # داده‌های ۲۴ اثر عکاسی و دسته‌بندی‌ها
│   │   └── themes.ts        # تعریف پالت‌های رنگی چهارگانه
│   ├── utils/
│   │   ├── cn.ts            # ترکیب کلاس‌های Tailwind
│   │   └── format.ts        # تبدیل اعداد فارسی و ساخت تصویر جایگزین برداری
│   ├── App.tsx              # کامپوننت ریشه برنامه
│   ├── index.css            # استایل‌های پایه، تایپوگرافی و انیمیشن‌ها
│   └── main.tsx             # نقطه ورود React
├── index.html               # سند اصلی HTML با پیکربندی RTL و فونت‌ها
├── package.json             # وابستگی‌ها و اسکریپت‌های اجرا و ساخت
├── tsconfig.json            # تنظیمات TypeScript
└── vite.config.ts           # تنظیمات Vite
```

## راه‌اندازی و اجرا

### ۱. نصب وابستگی‌ها

```bash
npm install
```

### ۲. اجرای محیط توسعه (Development)

```bash
npm run dev
```

### ۳. بررسی نوع‌ها و ساخت نسخهٔ نهایی (Production Build)

```bash
npm run build
```

### ۴. پیش‌نمایش نسخهٔ ساخته‌شده

```bash
npm run preview
```

## انتشار روی GitHub Pages

این پروژه به‌صورت خودکار از طریق **GitHub Actions** (`.github/workflows/deploy-pages.yml`) با هر بار Push یا Merge به شاخهٔ `main` ساخته و روی **GitHub Pages** منتشر می‌شود:

- **آدرس نمایش آنلاین:** [https://rahmaniho.github.io/RedLine/](https://rahmaniho.github.io/RedLine/)
- در تنظیمات ریپازیتوری (`Settings → Pages`)، گزینهٔ **Source** روی **GitHub Actions** قرار دارد و مسیر نسبی فایل‌ها (`base: "./"` در `vite.config.ts`) به همراه `404.html` و `.nojekyll` پیکربندی شده است.

## پیکربندی اختیاری فرم تماس

به‌صورت پیش‌فرض، درخواست‌های ارسالی در فرم تماس اعتبارسنجی شده و در مرورگر ذخیره می‌شوند. در صورت تمایل به اتصال فرم به سرور اختصاصی، فایل `.env` بسازید و متغیر زیر را تنظیم کنید:

```env
VITE_FORM_ENDPOINT=https://your-api.example.com/inquiries
```
